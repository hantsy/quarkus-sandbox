# Explore the other examples

This final chapter covers the examples that do not fit the REST, GraphQL, or
messaging chapters.

| Sample | What it demonstrates |
|---|---|
| [`multipart`](https://github.com/hantsy/quarkus-sandbox/tree/master/multipart) | Multipart request and response bodies, including file upload |
| [`quartz`](https://github.com/hantsy/quarkus-sandbox/tree/master/quartz) | Quartz scheduling with Hibernate ORM, Flyway, and PostgreSQL |

Each sample is a standalone Maven project with its own wrapper. Check its
`pom.xml`, application configuration, and any Compose file before you run it.

## Browse the legacy samples

The [`legacy`](https://github.com/hantsy/quarkus-sandbox/tree/master/legacy)
directory keeps older Java 8, RxJava 2, Vert.x, and Hibernate Reactive
examples. These modules are historical references; use the main repository
modules when you want to follow current sample code.
