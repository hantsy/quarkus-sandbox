# Part 1: Getting started

Build the same posts API using two programming models supported by Quarkus.
The first recipe uses Quarkus REST, Hibernate Reactive, and Panache. The
second uses Spring Web and Spring Data JPA extensions on Quarkus.

These are standalone samples, not one shared application. Run each module
separately and check its configuration before connecting a database.
